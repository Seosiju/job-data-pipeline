## 1. 에이전트란 무엇인가?

**에이전트(Agent)**는 특정 역할을 수행하도록 미리 설정된 AI 도우미입니다.

일반 AI와의 차이점:

| 일반 AI | 에이전트 |
|---------|----------|
| 매번 역할을 설명해야 함 | 역할이 미리 정의되어 있음 |
| 일관성 없는 결과 | 항상 같은 형식으로 분석 |
| 무엇을 해야 할지 모름 | 해야 할 일을 알고 있음 |

### 비유로 이해하기

- **일반 AI**: 아무 지시 없이 출근한 신입사원
- **에이전트**: 업무 매뉴얼을 숙지한 전문 컨설턴트

---

## 2. 우리가 만든 에이전트: repo-strategist

### 역할
프로젝트의 **현재 상태를 분석**하고 **다음에 무엇을 해야 하는지** 알려주는 전략 컨설턴트

### 언제 사용하나?
- 프로젝트를 처음 시작할 때 ("이 프로젝트 뭐가 어떻게 되어있어?")
- 작업을 완료한 후 ("다음에 뭐 해야 해?")
- 방향을 잃었을 때 ("지금 상태가 어떤지 파악해줘")

### 사용 방법
Claude Code에서 다음과 같이 말하면 됩니다:
```
프로젝트 현황 좀 파악해줘
```

## 3. 에이전트가 하는 일

### 3.1 코드 분석 도구 실행

에이전트는 다음 도구들을 사용해 **객관적인 수치**를 수집합니다:

| 도구 | 하는 일 | 비유 |
|------|---------|------|
| **tokei** | 코드가 몇 줄인지 센다 | 책의 페이지 수 세기 |
| **radon** | 코드가 얼마나 복잡한지 측정 | 문장의 가독성 점수 |
| **pytest** | 테스트가 통과하는지 확인 | 시험 점수 확인 |
| **pip-audit** | 보안 취약점이 있는지 검사 | 건강 검진 |

### 3.2 분석 리포트 생성

에이전트는 항상 **같은 구조**로 리포트를 작성합니다:

```
I.   현재 상태 평가      → 지금 어디까지 완성됐나?
II.  개발 히스토리 분석   → 어떤 과정을 거쳐 여기까지 왔나?
III. 전략적 권장사항     → 다음에 무엇을 해야 하나?
IV.  리스크 평가        → 주의해야 할 위험 요소는?
```

## 6. 자주 묻는 질문

### Q: 에이전트를 수정하고 싶으면?
`.claude/agents/repo-strategist.md` 파일을 편집하면 됩니다.

### Q: 새로운 에이전트를 만들고 싶으면?
`.claude/agents/` 폴더에 새 `.md` 파일을 만들면 됩니다.

### Q: 에이전트가 사용하는 도구가 없으면?
에이전트가 자동으로 감지하고, 수동 분석으로 대체합니다.
하지만 도구가 있으면 더 정확한 수치를 얻을 수 있습니다.

**도구 설치 방법**:
```bash
# macOS
brew install tokei

# Python 도구
pip install radon pytest-cov pip-audit
```

### Q: 분석 결과가 이해가 안 되면?
Claude Code에게 "이 결과 좀 쉽게 설명해줘"라고 요청하세요.

## 7. 용어 사전

| 용어 | 설명 |
|------|------|
| **커밋(Commit)** | 코드 변경사항을 저장하는 것. "저장 버튼"과 비슷 |
| **테스트(Test)** | 코드가 제대로 작동하는지 자동으로 확인하는 것 |
| **복잡도(Complexity)** | 코드가 얼마나 읽기 어려운지 나타내는 점수 |
| **리팩토링(Refactoring)** | 기능은 그대로 두고 코드를 깔끔하게 정리하는 것 |
| **로깅(Logging)** | 프로그램이 하는 일을 기록으로 남기는 것 |
| **Phase 1/2** | 이 프로젝트의 개발 단계 (1단계: 목록 수집, 2단계: 상세 정보 수집) |
