## 발견된 이슈 및 해결

### 1. 테스트 데이터 오염

- **문제**: DB에 `example.com` 도메인의 테스트 데이터 293건이 남아 있어 Phase 2에서 불필요한 크롤링 시도
- **해결**: 테스트 데이터 삭제 후 깨끗한 상태에서 검증 진행
- **권장**: 테스트 실행 후 cleanup 또는 별도 테스트 DB 사용

### 2. Phase 2 오래된 공고 접근

- **문제**: 기존 DB의 오래된 공고가 삭제된 경우 "채용공고가 존재하지 않습니다" 알럿 발생
- **현상**: Phase 2에서 JD 접근 실패 → 쿨다운 발생 → 전체 속도 저하
- **권장**: stale 공고에 대한 Phase 2 스킵 로직 또는 JD 접근 실패 시 빠른 스킵 고려

### 3. Super 회사 페이지 timeout

- **문제**: `Co_Read` → `Super` 리다이렉트 시 기존 selector가 매칭되지 않아 timeout
- **현상**: 일부 회사 페이지에서 반복 실패
- **권장**: Super 페이지용 selector 추가 또는 리다이렉트 후 URL 캐시 저장
